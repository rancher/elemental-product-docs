:description: Configure the managed operating system version channel by editing the YAML file to specify the desired update settings and ensure the system stays up to date
.managed-os-version-channel-json.yaml
[,yaml]
----
apiVersion: elemental.cattle.io/v1beta1
kind: ManagedOSVersionChannel
metadata:
  name: elemental-versions
  namespace: fleet-default
spec:
  options:
    URI: "https://raw.githubusercontent.com/rancher/elemental-product-docs/main/docs/1.9/modules/en/examples/upgrade/versions.json"
    Timeout: "1m"
  type: json
----
