= Valid Versions
:description: Find valid versions for the kubernetesVersion field using {rancher-product-name} metadata and the provided commands
:revdate: 2026-11-25
:page-revdate: {revdate}

The list of valid versions for the `kubernetesVersion` field can be determined from the {rancher-product-name} metadata using the following commands.

*K3s:*

[,bash]
----
curl -sL https://raw.githubusercontent.com/rancher/kontainer-driver-metadata/release-v2.6/data/data.json | jq -r '.k3s.releases[].version'
----

*RKE2:*

[,bash]
----
curl -sL https://raw.githubusercontent.com/rancher/kontainer-driver-metadata/release-v2.6/data/data.json | jq -r '.rke2.releases[].version'
----
