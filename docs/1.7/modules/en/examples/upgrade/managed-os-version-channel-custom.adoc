:description: Configure the managed OS version channel custom settings by editing the .managed-os-version-channel-custom file
.managed-os-version-channel-custom.yaml
[,yaml]
----
apiVersion: elemental.cattle.io/v1beta1
kind: ManagedOSVersionChannel
metadata:
  name: elemental-channel
  namespace: fleet-default
spec:
  options:
    image: registry.suse.com/rancher/elemental-channel:latest
  type: custom
----
